# Dados do Painel de Editais (QCA)

Arquivo de dados públicos usado pelo painel HTML da equipe. Gerado automaticamente
todo dia pelo projeto https://github.com/Gabrielcumaru/monitoramento-editais (privado).

Contém apenas informações já públicas nos sites de origem (editais e páginas de
empresas patrocinadoras). Não contém dados de clientes nem anotações internas.
